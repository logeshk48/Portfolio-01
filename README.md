# Portfoliko

Personal site for **Logesh** — Software Developer · AI Builder · Builder @ LetsCook

## Stack
Next.js 16 (App Router) · TypeScript · Tailwind v4 · React Three Fiber · GSAP · Lenis · Motion

## Design system — "Solder & Signal"
Two accents that carry meaning. Copper is the hardware era, signal-blue is the
software era. The page migrates from one to the other during the boot sequence.

| token | hex | role |
|---|---|---|
| `void` | `#08090B` | page |
| `board` | `#0E1013` | raised panels |
| `trace` | `#1C2026` | hairlines |
| `silk` | `#EDEFF2` | display text |
| `legend` | `#8A9199` | body / secondary |
| `copper` | `#C2793E` | hardware · past |
| `signal` | `#6E8BFF` | software · present |

Type: **Clash Display** (display) · **Satoshi** (body) · **Geist Mono** (all metadata)
